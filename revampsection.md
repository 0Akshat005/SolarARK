# SolarARK — Premium “From Rooftop to Running System” Section

Redesign the section immediately below the hero on:
https://solar-ark-sigma.vercel.app/

The provided reference image is the SINGLE visual source of truth for the composition, spacing, hierarchy, proportions, and overall visual direction.

Do not reproduce this as a generic SaaS/WordPress card section.
Do not add unnecessary cards, pills, badges, gradients, floating containers, or oversized UI elements.
The result must feel like a premium architectural/engineering brand website: calm, precise, editorial, minimal, and intentional.

- reliability
- premium residential solar

~520–600px maximum.

## 11. MICRO-INTERACTIONS

Keep motion refined.

On section reveal:
- heading: subtle fade + 12px upward movement
- paragraph: slight delayed reveal
- timeline: line draws from left to right
- nodes: fade/scale from 0.94 → 1
- illustration: very subtle opacity reveal

On hover over each journey stage:
- node glow increases slightly
- icon shifts 1–2px
- corresponding stage text gains slight emphasis
- timeline segment can brighten subtly

Do NOT use:
- bouncing animations
- dramatic parallax
- excessive blur
- spinning icons
- large scale transforms
- gimmicky scroll effects

Motion should feel like an engineered product, not a template animation.
